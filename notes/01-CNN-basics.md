# 图像识别
  图像有三个通道,分别是红、绿、蓝（RGB）。每个像素的值介于0-255，其中0是黑色、255是白色。所以，计算机看到的图像是：图像高度 x 图像宽度 x 颜色通道的三维数组。同一个物体在不同环境下，图像会不同：
  - 视角变化（不同视角观察一个物体，外观可能不同）
  - 2、尺度变化（同一个物体距离摄像头越远，在图片中所占据的像素越少)
  - 3、形变(比如人可以站着、坐着、蹲着等)
  - 4、遮挡
  - 5、光照变化
  - 6、背景杂乱
  - 7、类内差异（同一类别物体，外观存在差异）

一个好的图像识别没模型需要具备两种能力：
  - 对物体的角度、大小、光照和背景发生变化时保存稳定识别
  - 对类别差异保持敏感，能够区分外观相似但实际类别不同的物体
# CNN卷积神经网络基本原理
## 一、结构
### 1、卷积层Conv
  主要提取图像特征：其中底层提取边缘、线条；中间层提取纹理；高层提取轮廓以及目标整体
  - 卷积核：一个小矩阵，在图像矩阵上滑动，对应位置相乘再求和，得到输出值
  - 步长stride：卷积核每次滑动多少个像素，步长越大输出特征图越小
  - 填充padding：在图像外围补0，same padding保证输出核输入尺寸一样，valid不补边，输出缩小
  - 多卷积核：一组卷积核输出一张特征图，多个卷积核就输出多张特征图，捕捉不同特征。
  - 输出特征图公式：I输入尺寸，K是卷积核大小，P填充，S步长

### 2、激活层Activation
  卷积是线性运算，叠加非线性，网络才能学习复杂模式，ReLU：收敛快，抑制负数值
### 3、池化层Pooling
  降采样，缩小特征图尺寸，减少参数量，保留主要特征，一定程度抗位移扰动，（不用参数学习）
  - 最大池化MaxPool：取窗口最大值，保留显著特征（常用）
  - 平均池化AvgPool：取窗口平均值，保留整体背景信息
  - 全局平均池化GAP：对整张特征图求通道方向全局均值，把H*W*C变成1*1*C，来替代降低参数量，抑制过拟合
  2x2池化，步长2，特征图长宽直接减半
### 4、全连接层FC
  把二维的特征图展平成一维向量，全部神经元互相连接，做最后的分类回归等（参数量巨大，当前CNN用全局平均池化GAP替代全连接层（减少过拟合））
### 5、正则层Dropout和归一化层
  dropout：训练时随机关闭一部分神经元，防止网络过拟合
  归一化：对每一批特征做标准化，把分布拉回均值0方差1；加速收敛，降低对初始化的依赖，一定程度抑制过拟合，放在卷积和激活之间
## 二、三大思想
### 1、局部感受野
  人识别图像先看局部，再组合看整体。卷积核只看一小块像素，不需要一次性感知整张图片
### 2、权值共享
  同一个卷积核再整张图滑动，共用同一套权重参数（极大减少参数量，但是不同卷积核权重不共享）
### 3、空间不变性
  同样的特征，出现再图片不同位置，卷积核都可以检测出来，物体平移后依然可以识别
## 三、完整的前向传播流程（图像分类）
  输入RGB图片（3通道）:
  -> 卷积+ReLU（提取边缘纹理）
  -> 池化（缩小尺寸）
  -> 卷积+ReLU（提取高级特征）
  -> 池化
  -> (重复多组卷积+池化层)
  -> 展平或者全局平均池化
  -> 全连接层
  -> Softmax输出各类别概率
## 四、CNN与全连接神经网络相比
  将一张三通道的彩色图像拉平成一维向量参数量会很大。卷积会保留图像的二维空间结构，卷积核再图片上滑动，逐步寻找边缘、纹理、形状和物体。
  图像任务使用CNN，主要不是因为全连接网络完全不能处理，而是因为CNN通过局部连接和参数共享，以更少的参数，更高的数据利用效率，学习到了更适合图像的特征
## 五、经典CNN网络结构
  ### 1、LeNet-5（1998）：
      网络结构七层，输入32*32*1的灰度单通道（使用tanh激活，平均池化）：
      （1）C1卷积层：6个5*5卷积核，stride=1（输出28*28*6）
      （2）S2下采样：2*2平均池化 stride=2（输出14*14*6）
      （3）C3卷积层：16个5*5卷积核（输出10*10*16）
      （4）S4下采样：2x2平均池化（输出5*5*16）
      （5）C5卷积层：120个5*5卷积核（输出1*1*120）
      （6）F6全连接层：84神经元
      （7）output输出：10个输出(0-9数字)
  ### 2、AlexNet（2012）
    整体5卷积层+3全连接层，输入224*224*3 RGB彩色图
    创新：
      ReLU激活，解决深层梯度消失
      Dropout（0.5）放在全连接层，对抗严重过拟合
      重叠最大池化：3*3池化窗口，stride=2，窗口发生重叠，特征信息保留更好
      GPU分组卷积训练：当年单卡显存不足，网络拆分两组，两块GPU并行运算
      大规模图像数据增强：随机裁剪、镜像、颜色扰动
      LRN局部响应归一化
    缺点：
      参数量巨大约6000万，绝大多数参数集中再三层全连接
      使用大卷积核：第一层11*11，计算开销高
  ### 3、VGGNet（2014）
    13层卷积层+3层全连接层，全部统一使用3*3小卷积核，通过堆叠小卷积模拟大卷积感受野
    输入224*224，多组Conv3*3+ReLU堆叠，每若干卷积后执行一次2*2MaxPool，一共5次池化，特征图长宽连续减半32倍，最后展平输入三层全连接层，Softmax输出1000分类
    参数量高达1.38亿，大部分来自三层全连接层
  ### 4、GoogleNet（2014）
    网络深度22层，参数量仅400万
    核心单元：Inception模块，不是简单串行堆叠卷积，采用多分枝并行结构，同时提取多尺度特征，再把不同分支特征在通道维度拼接Concatenate
    Inception-v1模块4条并行分支：
      1、1*1卷积（通道变换，轻量卷积）
      2、1*1卷积降维，3*3卷积（中等感受野）
      3、1*1卷积降维，5*5卷积（大感受野）
      4、3*3最大池化，1*1卷积（池化后通道调整）
    * 关键技巧：1*1卷积降维，如果直接并行3*3，5*5，通道数爆炸，计算量保障，先1*1把通道压缩，再做大卷积，显著降低算力消耗
    * 四条分支输出特征图保持同样H，W，直接再通道维度拼接输出，送入下一个Inception模块。
  ### 5、ResNet残差网络（2015）（突破深度上限，解决网络退化问题）
    普通CNN网络，单纯增加层数，训练集准确率反而下降，称为网络退化Degradation Problem。
    ResNet提出残差块Residual Block+shortcut跳跃连接（skip connection），可以训练几十到上千层网络，ResNet-18/34(基础块)，ResNet-50/101/152（瓶颈Bottleneck块）
      1、基础块BasicBlock(ResNet18/34):两次3*3卷积堆叠，适合浅层ResNet
      2、瓶颈层Bottleneck（ResNet50/101/152）：1*1降维，3*3卷积，1*1升维，用1*1卷积压缩中间通道，降低网络计算量
   输入经过7*7卷积+最大池化，然后多组残差块堆叠；全局平均池化，一层全连接输出分类 
   解决了深度退化，可以训练极深网络
   训练简单稳定，预训练模型应用极广，目标检测，分割几乎都以ResNet作为骨干网络Backbone
   局限：简单恒等跳连只做加法，对特征通道交互有限，后续衍生DenseNet，SENet等
